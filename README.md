# Unit Converter (Android)

แอป Android แปลงหน่วยที่ใช้ในงานวิศวกรรม เขียนด้วย Kotlin + Jetpack Compose
ไอคอนแอปใช้โลโก้ของ บริษัท วิทย์มงคล จำกัด (ไฟล์ต้นฉบับตัดพื้นหลังแล้วอยู่ที่ `icon-512.png`)

## หมวดหน่วย (10 หมวด)
อุณหภูมิ · ความดัน · อัตราการไหล · ความเร็ว · น้ำหนัก · เวลา · ระยะ · พื้นที่ · ปริมาตร · พลังงาน

ใช้งาน: พิมพ์ค่า เลือกหน่วยต้นทาง แล้วแอปแสดงผลทุกหน่วยในหมวดพร้อมกัน
แตะแถว = ใช้เป็นหน่วยต้นทาง · กดค้าง = คัดลอกค่า

## คำสั่งเสียง
แตะปุ่มไมโครโฟนมุมขวาล่าง แล้วพูด ระบบจะสลับหมวด ใส่ค่า และเลือกหน่วยให้เอง
ธงชาติมุมขวาบน (ไทย / อังกฤษ) ใช้สลับภาษาทั้งแอป ทั้งชื่อหมวด ชื่อหน่วย ข้อความ และภาษาที่ใช้รู้จำเสียง
แอปจำภาษาที่เลือกไว้ ครั้งแรกจะใช้ภาษาตามเครื่อง (ภาษาไทยถ้าเครื่องตั้งเป็นไทย ไม่เช่นนั้นเป็นอังกฤษ)
ข้อความภาษาอังกฤษอยู่ใน `Strings.kt`

ตัวอย่างประโยค
- แปลง 100 CFM เป็น ลูกบาศก์เมตรต่อชั่วโมง
- แปลง 3 กิโลกรัมต่อตารางเซนติเมตร เป็น บาร์
- ติดลบ 40 องศาเซลเซียส เป็น ฟาเรนไฮต์
- แปลง 2 ไร่ เป็น ตารางเมตร
- convert 5 bar to psi
- convert 100 gpm to liters per minute

ข้อควรรู้
- ใช้หน้าต่างรู้จำเสียงของระบบ Android (ต้องมีแอป Google) จึงไม่ต้องขอสิทธิ์ไมโครโฟนในแอป
- ต้องออนไลน์ตามค่าเริ่มต้นของบริการเสียง Google
- ถ้าพูดแต่ปลายทาง เช่น "เป็นนิ้ว" แอปจะใช้หน่วยต้นทางที่เลือกอยู่
- เพิ่มคำเรียกหน่วยได้ที่ `aliases` ใน `Units.kt` (ตัวอักษรเล็ก, ไทยเขียนติดกัน, ใช้ "ต่อ" / " per ")

## วิธีได้ไฟล์ APK ผ่าน GitHub
1. สร้าง repository ใหม่บน GitHub แล้ว push โฟลเดอร์นี้ขึ้นไป (branch `main`)
2. ไปที่แท็บ **Actions** → workflow **Build APK** จะรันอัตโนมัติ (หรือกด *Run workflow*)
3. เมื่อรันเสร็จ ดาวน์โหลดไฟล์ APK ได้จาก **Artifacts** ของการรันนั้น
4. ต้องการแจกเป็น Release: สร้างแท็ก เช่น `git tag v1.0 && git push origin v1.0`
   ไฟล์ `app-debug.apk` จะถูกแนบในหน้า Releases อัตโนมัติ

ติดตั้งบนมือถือ: เปิดไฟล์ APK แล้วอนุญาต "ติดตั้งจากแหล่งที่ไม่รู้จัก"

## Build เองในเครื่อง
เปิดโฟลเดอร์ด้วย Android Studio (JDK 17) แล้วกด Run หรือใช้ `gradle assembleDebug`

## การเพิ่มหน่วย
แก้ไฟล์ `app/src/main/java/com/engunits/converter/Units.kt`
หน่วยเชิงเส้นเพิ่มได้บรรทัดเดียว เช่น `lin("ชื่อหน่วย", "สัญลักษณ์", ตัวคูณเทียบหน่วยฐาน, "คำเรียกด้วยเสียง", ...)`

## หมายเหตุ
- APK เป็นแบบ debug (เซ็นด้วย debug key) เหมาะกับใช้งานส่วนตัว ถ้าจะขึ้น Play Store ต้องทำ release build และเซ็นด้วย keystore ของตัวเอง
- นิ้วน้ำ (inH₂O) ใช้ที่ 4°C, บีทียูเป็นแบบ International Table, แกลลอนระบุ US/UK แยกกัน
